# Contador-de-bases-de-Secuencias-ARN
Herramienta de conteo de bases, para calculo de sumatorias de bases en secuencias de ARN.

## Estructura del proyecto
- datos/: contiene secuencias de ARN de ejemplo para pruebas de la herramienta.
- documentacion Base/: documentación adicional del proyecto.
- Documentacion/: contiene la documentación metodológica del proyecto.
- Herramienta de Conteo/: implementación principal de la herramienta
- Solicitudes de Conteo/: secuencias de entrada para análisis.
- Comentarios Generales7: observaciones y notas de trabajo.
- scripts/: contiene los scripts para el procesamiento y conteo de bases en secuencias de ARN.
- resultados/: almacena los resultados.

## Objetivos
- Analizar secuencias de ARN.
- Contabilizar la frecuencia de aparición de cada base.
- Generar resultados que faciliten el análisis de las secuencias estudiadas.

## Instrucciones de uso
1. Introducir una secuencia de ARN en el sistema.
2. Ejecutar la herramienta de conteo.
3. Revisar los resultados generados en la carpeta de resultados.
4. Consultar la documentación para interpretar los resultados.

## Estado del proyecto
Proyecto académico desarrollado como práctica de control de versiones mediante Git y GitHub.
